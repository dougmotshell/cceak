# Pesquisa web

- O link `share.google` fornecido pode não ser acessível diretamente por ferramentas de leitura; registrar o link original e confirmar a entidade por fontes independentes.
- O nome da instituição é ambíguo; localidade e CNPJ devem ser usados antes de atribuir endereço, horários ou redes sociais.
- A coleta automatizada é limitada a quatro workers por padrão, pois é uma tarefa de rede e não exige alto uso de CPU.
